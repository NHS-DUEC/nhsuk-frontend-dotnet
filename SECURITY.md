# Security policy

## Reporting a vulnerability

Please don't report security problems in public issues.

Use GitHub's private reporting: on this repository, go to **Security → Report a vulnerability**. Only the
maintainers can see the report. This is a volunteer-maintained community project, so we can't promise a response
time, but we will acknowledge reports as soon as we can.

If the problem is in nhsuk-frontend itself (its CSS, JavaScript or templates) rather than in this port, please
report it to the [nhsuk-frontend](https://github.com/nhsuk/nhsuk-frontend) maintainers instead.

## Supported versions

Only the latest release receives fixes.
